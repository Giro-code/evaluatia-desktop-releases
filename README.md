# EvaluatIA Desktop

Repositorio público para distribuir los instaladores oficiales de EvaluatIA para Windows. El código de la aplicación se mantiene en su repositorio privado.

Descarga desde [EvaluatIA](https://evaluatia.net/desktop). No necesitas una cuenta de GitHub.

Cada publicación incluye el instalador y su archivo SHA-256. La versión 0.1.2 no tiene firma Authenticode; Windows o Microsoft Edge pueden mostrar un aviso por su reputación o firma. Alojar el archivo aquí no elimina esos avisos.
